## Contribution

In this module, I implemented an energy analysis workflow to evaluate building performance using energy signature methods and predictive modeling.

The work includes:
- Deriving energy signatures from time-series data (hourly, daily, and weekly)
- Comparing energy behavior before and after optimization
- Developing a prediction model (LSTM) to estimate energy consumption
- Visualizing results to highlight performance improvements

This module was designed as a separate component to maintain a clean and modular project structure.
